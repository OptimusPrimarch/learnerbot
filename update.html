Update your sheet's script

About two minutes. This replaces only the code inside your copy of the sheet. Your goals, your Groq key, your access token and your connected phones are not touched, and the web address stays the same, so nothing needs reconnecting.

Look for the button first. If LearnerBot shows Update now on its yellow banner (or in ⚙), press that instead: it does all of this for you in a few seconds. Use the steps below only when that button is missing or says it could not finish.

1. Copy the new code

or download it as a file

Your browser did not allow copying automatically. Click inside the box, press Ctrl+A then Ctrl+C (Cmd on a Mac), and carry on.

2. Paste it over your script

  1. Open your LearnerBot sheet and choose Extensions → Apps Script.
  2. In the file list on the left, click Code.gs. It should be the only file.
  3. Click inside the code, press Ctrl+A to select all of it, then Ctrl+V to paste the new code over it (Cmd instead of Ctrl on a Mac).
  4. Click the Save icon (or press Ctrl+S).

3. Publish the new version

Saving is not enough: the web app keeps running the old code until you publish a new version of it.

  1. Click Deploy → Manage deployments.
  2. Click the pencil (Edit) icon on your web app.
  3. Under Version, choose New version, then click Deploy.

Choose Manage deployments and edit the existing one. Do not choose New deployment: that makes a second web app with a different address, and LearnerBot would keep talking to the old one.

4. Check it worked

Reload LearnerBot. The update notice disappears and ⚙ → Your sheet's script says it is up to date.

If something goes wrong

  • Saving shows a red error mentioning "already been declared". There is more than one file in the script. Delete every file except Code.gs (hover over a file, click the three dots, Delete), then paste again.
  • LearnerBot still says it is out of date. The new version was probably not published. Repeat step 3 and make sure New version is chosen.
  • LearnerBot says it cannot reach your backend. If you made a New deployment by mistake, copy its Web app URL from Deploy → Manage deployments into ⚙ in LearnerBot, or delete it and edit the original instead.
  • Google asks you to review permissions. That is normal after an update. Choose Review permissions, then Advanced → Go to … (unsafe) and allow it, exactly as when you first set it up.
